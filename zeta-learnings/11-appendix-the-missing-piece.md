# Appendix — the missing piece: tally completes Claude Code's own SDD

*Added 2026-08-14, minutes before the session compact, after the operator
surfaced the last alignment. This is the decisive statement of what zeta
actually is.*

Anthropic ships spec-driven development as **primitives, deliberately
unfinished**: Plan Mode (a read-only sandbox that authors a plan before
write tools unlock), CLAUDE.md as repo-native constitution, specs as plain
committed markdown — and no framework. Where GitHub wrapped those ideas in
spec-kit's template ceremony and AWS sealed them inside Kiro's IDE,
Anthropic left the scaffolding open on purpose, and their own published
engineering shape — orchestrator-workers, ephemeral sandboxes, closed-loop
doctrine files, multi-agent reviewers in shadow mode until they earn trust,
humans at highest leverage only — is exactly the architecture they did not
productize. **That unbuilt half is the authority plane.** The tally spec
layer — which is, honestly named, a set of skills for Claude plus one
linter crate riding an execution machine that already exists — is the same
move that built tally's flows out of ultracode workflows: take what the
model and its harness natively do, and give it a deterministic,
witnessed runtime. We drew the work plane from ultracode's deterministic
orchestration; zeta draws the authority plane from Plan Mode's contract
discipline. Both times, the house contribution is not a new idea but the
*hardening* of Anthropic's own primitive into committed, gated, provable
form.

The mapping is one-to-one, and each arrow is a hardening. Plan Mode's
read-only context gathering becomes the sitting's census and the
crystallization lanes — witnessed, not ambient. Its ephemeral PLAN.md
becomes the ratified spec and derived worklist — committed bytes with a
pinned sha, diffable at claim granularity, *durable where Plan Mode is a
session state*. Its gated tool permissions become conflict domains, the
deny-list, and the tree-delta certification — enforcement at the runtime,
after the fact, against the repo itself. Its approve-to-unlock state bit
becomes the ratification commit and worklist admission — an auditable act
on the trust root instead of a keystroke. Plan Mode is the right contract
with no memory, no witness, and no proof; the authority plane is Plan Mode
made permanent.

The "blind trust" doctrine — the execution agent treats the specification
as an authoritative contract, never a suggestion — is not something zeta
must build; **tally already runs it.** Context starvation is D68: goal
plus readFirst is the worker's entire context. Withheld rationale is the
consortium's own handoff rule: every name it would otherwise invent, no
reasoning it could re-litigate. Runtime interception is ownership
certification. And the one failure mode blind trust cannot absorb — the
spec itself is wrong — is precisely what the rest of the machine
answers: escalation instead of improvisation (the impossible envelope is
a claim, never a verdict), the judge's typed verdict gating retries, and
the amendment proposal rendered as a ready worklist diff — the closed
loop *spec → execution → failure → back to the spec author* that
Anthropic describes internally, running here as committed machinery with
receipts. Even shadow mode has its house twin: the judge's tier is
downgradeable only by corpus-replay measurement — reviewers earn trust on
numbers, never on impression.

So the decisive statement, once: **Claude Code ships the primitives;
spec-kit and Kiro decorate them; tally completes them.** Plan mode made
durable (session state → ratified, pinned, linted artifact). Blind trust
made enforceable (prompt discipline → runtime certification). The
feedback loop made typed (vibes → envelopes, verdicts, and a questions
queue). The doctrine file made honest (ambient CLAUDE.md accretion →
skills rewritten by gated campaign tasks). That is why zeta is an
overnight and not a quarter: the execution machine, the trust model, and
the enforcement ladder all exist; what lands is the claim grammar, the
linter that speaks it, the author-spec skill, and the first spec — the
missing piece, snapped into a machine that was shaped, from the
beginning, to receive it.

Zeta, therefore, in one line: **tally teaching Claude Code's spec
instincts to leave receipts** — at once tally changing itself and the
first witnessed documentation-in round-trip, and the dress rehearsal for
running the same contract over agency's twenty frozen domains.
